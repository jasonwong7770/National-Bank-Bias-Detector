# National-Bank-Bias-Detector
Trading analysis tool that helps traders detect harmful behavioral patterns to combat common behavioral biases, including:
- Overtrading
- Loss Aversion
- Revenge Trading
- FOMO (Fear of Missing Out)

By understanding these patterns, traders can make more informed decisions and increase their chances of consistent success.

# Setup Commands
In the current directory, run:
```bash
uvicorn api:app --reload --port 8000
```

Navigate to the frontend folder and run:
```bash
npm install
npm run dev
```
